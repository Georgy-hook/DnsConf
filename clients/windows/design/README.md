# Графические исходники

В `assets/` сохранены PNG Image Gen в исходном размере: герой, иконка приложения, флаги, отдельные иконки и ранний атлас. В `imagegen-prompts.json` и `imagegen-prompt.txt` находятся промпты. Локальные пути входных изображений из технических аргументов генерации не публикуются.

Текущий GUI использует подготовленные ресурсы из `_service/assets/ui/` и иконку `_service/assets/app.ico`. Мастер-файлы из этой папки в готовый ZIP не включаются; они сохранены для будущей доработки без повторного сжатия уже уменьшенных иконок.
