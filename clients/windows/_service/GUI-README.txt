NextDNS GUI — техническая справка 28.10.2026
WinPS 5.1 / WPF, C# launcher. Build-Launcher.ps1 -Bin собирает _service\bin\NextDNS.exe.
Аргументы: -Tray (скрытый запуск), -Repair (восстановление), -SmokeTest,
-RenderPreview -PreviewPath <path>. Без аргументов открывается главное окно.
-Repair -SmokeTest проверяет XAML восстановления без системных действий.

DesktopInstance использует mutex + event на пользователя/сессию/папку/режим.
Событие активации читается в DispatcherTimer; PS не вызывается из CLR-потоков.
Главное окно использует Application.Run + OnExplicitShutdown, чтобы Hide()
не завершал цикл сообщений. NotifyIcon очищается при полном выходе.
Автозапуск: HKCU\Software\Microsoft\Windows\CurrentVersion\Run,
значение NextDNS Connection Manager, абсолютный путь к EXE + -Tray.
Переносная сборка сама не включает автозапуск и не содержит личных настроек.

ConnectionWorker.ps1 параллельно запрашивает случайные поддомены через DNS
Windows. Общий предел ожидания 12 секунд; родитель ограничивает worker
20 секундами. Временный результат удаляется после чтения.
В фоне повторяется только DNS-проверка, каждые 5 минут; HTTPS/кеш/версии
проверяются при запуске, явной проверке и применении настроек.
connection-routes.json — отдельный расширяемый каталог ожидаемых адресов.
Успешная DNS-проверка всегда имеет AttachmentsVerified=false.

BrowserRecovery.ps1 запрашивает обычное CloseMainWindow, без Kill.
Второе окно того же процесса получает отдельный запрос; повторный запрос
тому же окну не отправляется. После 25 секунд ожидания — объяснение причины.
Только отсутствие всех процессов Chrome позволяет запросить новый запуск
с --restore-last-session. Новый видимый процесс подтверждает только перезапуск.
Процессы текущей Windows-сессии; отдельные --user-data-dir профили не затрагиваются.
Перед операцией требуется явное подтверждение сохранения работы в GUI.
Desktop Dot и браузер Chrome различаются в текстах и действиях.

Profiles.ps1 и RepairWorker.ps1 сохраняют проверку SID, хеша hosts, резервные
копии, защиту путей и пользовательское подтверждение UAC при изменении hosts.
Растры/assets и пользовательский каталог profiles.json в этом обновлении
не заменяются. Текущая анимация останавливается у скрытого главного окна.

NetworkSetup.ps1 устанавливает NextDNSBridge из bridge\ в Program Files.
Служба LocalService, Auto, восстановление SCM через 5/15/30 секунд.
Отдельный Python runtime запускается из защищённого каталога с -I.
DNS слушает только loopback UDP/TCP, IPv4/IPv6. Внешний транспорт — DoH
NextDNS, TLS 1.3 с обычной проверкой сертификата. Первый ClientHello
разделяется на два корректных TLS records; данные handshake не изменяются.
Открытый DNS и альтернативные провайдеры в качестве обхода не используются.
Профиль извлекается из текущего DoH Windows; ID не включается в ZIP.
Runtime проверяется по runtime-hashes.json. Исходники C#/Python и лицензия
Python входят в переносную сборку. Пересборка службы: bridge\Build.ps1.

Инсталлятор сохраняет исходные DNS по GUID адаптера, состояние старой
службы, Start старого драйвера и автозапуск. Backup в ProgramData доступен
только Administrators/System. Код Program Files доступен пользователям
только на чтение. Прежний клиент и его драйвер отключаются в автозапуске;
работающий драйвер принудительно не выгружается. Restore возвращает сеть,
службу, Start драйвера и удаляет только свои помеченные исключения DiscordFix.
Установка/возврат/перезапуск требуют SID текущего пользователя и UAC.
Ошибка установки после изменения сети запускает возврат из backup.

Служба сохраняет status.json и boot-check.json без доменов запросов и URL.
boot-verified.json создаётся только при успешном тесте вскоре после старта
Windows; BridgeStatus.ps1 сверяет bootAt с текущей загрузкой. Автопроверка
DNS не доказывает загрузку вложения или работоспособность WebRTC.
BridgeStatus виден в главном окне и окне восстановления; план действий
и продолжение для UAC находятся внутри GUI.

Все PS1 сохранять UTF-8 с BOM (русский текст в Windows PowerShell 5.1).
Пакет собирать по разрешённому списку файлов; не включать run-results,
логи, backups, GUI-settings.json и локальный NextDNS-профиль.
